One line, one cat joke: "I asked my cat for emotional support. He sat on my laptop, deleted my work, and purred like he'd fixed it." Asked for comfort, got sabotage delivered with total confidence.

## Run it

```sh
node main.ts
```

`main.ts` writes the cat joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single line of 1–200 characters with no dash.
